# Phase 5：新旧数据集划分方法对比

对比同一个 backbone、同样用 ImageNet 预训练权重初始化，只改变训练/测试划分方式：

- **旧划分（legacy）**：`StandardizedSpectra` 全量数据，`train.py` 里固定 `random_state=42` 的 60/20/20 随机划分
- **新划分（nist_split）**：按分子来源（NIST vs SDBS）划分的 `NistSdbsSplit`，测试集分子来源、绘图风格和训练集完全不同

数据来自 `experiments/results/{backbone}/test_result.csv` 与 `experiments/results/{backbone}_pretrained/test_result.csv`，汇总在 [experiments/results/phase5_split_comparison.csv](../experiments/results/phase5_split_comparison.csv)。

## 说明

设计这个对比是想验证一个假说：旧的随机划分可能因为同分子/同来源绘图风格在 train 和 test 里都出现过，存在隐性的来源信息泄漏，虚高了性能；换成按来源（NIST/SDBS）划分后，测试集应该更接近真实的域外泛化场景，指标应该会掉。

**结果只有一半支持这个假说，不是一边倒的：**

- **resnet50 / resnet101 符合预期**：新划分下 F1 明显下降（-13%～-24%），AUC 也同步下降，和"旧划分虚高了性能"的假说一致。resnet101 降幅最大，是文档里原本建议重点看的backbone，这个结论站得住。
- **vgg16 相反**：新划分下 F1、AUC 反而都涨了（F1 +47%），和假说方向相反。
- **vit_b 看不出方向性**：两个划分下 F1 都只有 0.02～0.03，接近随机猜测的水平，ViT 在这个数据规模/训练设置下本身就没学出什么东西，这组对比对验证假说没有参考价值。

**没有定论的地方，留给后续讨论：**

1. vgg16 为什么反过来——是不是新划分下 SDBS 图像风格恰好和 vgg16 的浅层纹理特征更契合，或者旧划分里 vgg16 反而因为某种原因欠拟合／过拟合到旧数据的某种偏差上？需要具体看两边测试集上 vgg16 哪些标签的预测差异最大才能说清楚。
2. resnet50/101 的降幅是否真的来自"信息泄漏"，还是单纯因为新划分的训练集更小/分布更偏（训练集2785个样本里1126个是同分子的第二视角增强，可能没有旧划分下的原始训练集那么多样）？两者目前是混在一起的，没有做消融区分。

从零训练（`*_scratch`）的结果目前没有并入这张对比图（预训练权重初始化和从零训练混在一起会让"划分方式"这一个变量的效应说不清楚），如果需要可以再补一张三线对比图（旧划分预训练 / 新划分预训练 / 新划分从零）。
