# 红外光谱预测气味：研究计划与方案备选

## 1. 研究问题与核心假设

**目标**：给定一个分子的红外光谱图（实测值），预测其具有哪些气味描述符（120类多标签分类）。

**核心假设**：红外光谱不仅编码了官能团的"有/无"，还编码了峰位偏移（分子内环境效应）、峰强（浓度/纯度相关）、峰形（氢键、共轭）等信息，这些信息在纯结构指纹里无法获得，有助于提升气味预测精度。

**论文卖点（ICML定位）**：
- 证明光谱特征相对于结构指纹提供了增量信息（不是把官能团分析换了个马甲）
- 设计一个能让模型"自己学"哪些光谱区域对特定气味重要的架构（而非人工指定官能团）
- 在小样本多标签场景下提供可行的解决方案

---

## 2. 数据概况

| 项目 | 数值 |
|---|---|
| 总分子数 | 8503 |
| 有光谱的分子数 | 2892 |
| 气味标签数 | 120（二元多标签） |
| 光谱来源 | SDBS类型1（1767）/ 类型2（592）/ NIST重绘（533） |
| 图片尺寸 | 686 × 322，黑白 |

**标签稀疏性问题**：120个标签里很多只有几十个正例，部分甚至不到10个。必须处理严重的类内不平衡。

---

## 3. 特征提取方案（三选一，推荐方案A）

### 方案A：细粒度波数分箱向量（推荐）

从 `.jdx` 原始数值直接采样（NIST部分已有），SDBS 部分从标准化图像反向提取曲线（轮廓检测）。

- 将 400–4000 cm⁻¹ 均匀切成 N 个 bin（建议 N=360，每10 cm⁻¹ 一个）
- 每个 bin 取最小 %T（即最强吸收深度）
- 输出：360 维固定向量，不对齐到任何命名官能团

**优点**：
- 不人为指定"这是羰基区"，让模型自己找相关区域
- 远比直接用原始像素（686×322=221192维）低维
- 3000样本下可用 MLP / 1D-CNN / 简单Transformer

**缺点**：
- SDBS图片反向提取曲线有误差（峰检测 + 坐标系标定）
- 气相弱信号谱图已做自动拉伸，绝对强度不可直接比较不同来源

---

### 方案B：峰描述符向量

用信号处理方法（`scipy.signal.find_peaks`）自动检测 %T 曲线的局部极小值：

- 每个峰记录：峰位置（cm⁻¹）、峰深度（Δ%T）、半峰宽（FWHM）
- 取强度最大的 Top-K 个峰（K=30~50），不足补零 → 固定维度向量

**优点**：紧凑（3K 维），可解释（哪个峰贡献了什么），与分子振动模式直接对应

**缺点**：
- 峰检测对噪声敏感，弱信号谱中参数调节困难
- Zero-padding 后模型需要学会忽略填充位，不如 Transformer 自然处理变长序列

---

### 方案C：峰作为 Token 的 Transformer（方案B的增强版，可作为核心创新点）

将每条谱图的有效峰序列视作一段"分子振动语言"：

- 每个峰 → 3维向量 `(wavenumber, depth, fwhm)` + 可选的局部上下文嵌入
- 用 Transformer Encoder 做 Self-Attention
- 输出：CLS Token → 多标签分类头

**为什么适合 ICML**：
- Attention 权重可视化：直接显示哪些峰对哪个气味标签有贡献，具有化学可解释性
- 自然处理变长峰序列，不需要 zero-padding 的技巧
- 样本效率高（输入是峰的稀疏表示，参数量小）

**风险**：3000样本对 Transformer 来说偏少，需要较强正则化（dropout 0.3+、label smoothing、early stopping）

## 4. 基线对比（必选）

| Baseline | 输入 | 模型 | 说明 |
|---|---|---|---|
| B1 | Morgan FP（结构） | MLP / RF | 纯结构基线，不用光谱 |
| B2 | RDKit 描述符（结构） | MLP | 包含官能团、理化性质 |
| B3 | 谱图图片 | 2D-CNN | 直接吃原始像素 |
| B4 | 方案A (360维向量) | MLP | 细粒度分箱向量 + 简单模型 |
| B5 | 方案A + 结构指纹 | 融合MLP | 光谱 + 结构联合输入 |
| **主模型** | 方案C（峰Token） | Transformer | 核心方案 |

## 5. 实验方案

### 5.1 数据划分

- 5折交叉验证（3000样本太少，不能单独留出测试集）
- 按分层采样保证每折里各标签正例比例基本一致
- 注意：SDBS 和 NIST 来源的谱图不混在同一折里做验证（避免来源泄漏）

### 5.2 处理标签不平衡

- **Focal Loss** 代替 BCE（自动加权难例，减少大量负例主导梯度）
- 正样本权重：$w^+ = N_{neg}/N_{pos}$（逐标签计算）
- 对极少正例标签（< 20个）在消融时单独报告或合并分析，避免统计噪声夸大效果

### 5.3 评估指标

| 指标 | 说明 |
|---|---|
| Macro F1 | 主指标，各标签等权平均，对稀疏标签敏感 |
| Micro AUC | 辅助指标，评估整体排序能力 |
| Label-wise AP | 每个标签的平均精度，分析不同标签难度 |
| Top-K 精度 | 预测最可能的K个气味，实际应用价值视角 |

### 5.4 消融实验

1. 光谱类型消融：SDBS only / NIST only / 全部混合
2. 特征维度消融：N=90（40cm⁻¹）/ 180（20cm⁻¹）/ 360（10cm⁻¹）
3. 有无结构指纹的消融（光谱 alone vs 光谱+结构）
4. Peak Token数量K的消融（10/20/30/50）

## 7. 风险与备选

| 风险 | 触发条件 | 备选方案 |
|---|---|---|
| 光谱相对结构指纹无增量信息 | B1/B2 已经很强，加光谱没提升 | 转变角度：论文卖点变成"光谱数据的局限性分析"，或换任务（光谱->结构） |
| 样本太少Transformer过拟合 | 验证损失>训练损失，F1不稳定 | 退化为MLP + 方案A（分箱向量），或用预训练分子表示初始化 |
| SDBS图像反向提取曲线误差大 | 提取的向量噪声明显，B4效果异常差 | 只用NIST-only的533张（有干净数值数据），牺牲样本量换精度 |
| 标签分布太稀疏 | 大量标签AUC在0.5附近 | 合并语义相似标签（如 fruity/tropical/citrus 合并为"水果系"），减少标签数 |
